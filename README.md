# ECOM KG — сайт-макет Ассоциации (дизайн A «Торговый коридор»)

Готовый многостраничный сайт по ТЗ. Дизайн — направление A (индиго + тёплая бумага + янтарь, шрифты Fraunces + Inter). Чистый HTML/CSS/JS, без сборки. Все кнопки, ссылки, меню, фильтры и формы работают; платные сервисы (оплата, SMS, БД) — в демо-режиме, подключаются позже.

## Как открыть локально
- Дважды кликнуть `index.html` — откроется в браузере (нужен интернет для загрузки шрифтов).

## Как выложить в интернет за 2 минуты (бесплатно)
1. Открыть **app.netlify.com/drop**
2. Перетащить туда **всю папку сайта** (или файл `ecomkg-site.zip`).
3. Netlify выдаст ссылку вида `https://ваше-имя.netlify.app` — её можно сразу отправить.
4. Позже: подключить домен `ecomkg.kg` / `ecomkg.org` в настройках Netlify.

Альтернативы: Vercel (vercel.com), GitHub Pages, Cloudflare Pages — тоже бесплатно.

## Что работает / что демо
- **Работает:** вся навигация, меню «Ещё», выбор роли при входе, фильтры каталога, переключатель языка (KG/EN — сообщение «на 2 этапе» по ТЗ).
